# Task 02 Answer

## 1. 为什么 ./tools/recruit-info 能运行,而直接输入 recruit-info 可能找不到?

./tools/recruit-info 是带路径的写法,shell 会按该相对路径直接去当前目录下的 tools/ 子目录找到文件并执行;
而直接输入 recruit-info 时,shell 只会在 PATH 环境变量列出的目录中搜索,当前目录 . 和 tools/ 都不在 PATH 中,所以提示 command not found。

## 2. Shell 输入 ls 时如何找到程序?

shell 会按顺序搜索 PATH 环境变量中的每个目录,找到第一个名为 ls 的可执行文件就执行(通常是 /usr/bin/ls),可以用 command -v ls 查看实际找到的路径。
